Cric JournalDevelopers

API & MCP for developers and AI agents

Everything the website shows is available through a public REST API (JSON, OpenAPI 3.1), live Server-Sent Event streams, and a Model Context Protocol server for AI assistants.

REST API

Base URL: · Spec: /api/openapi.json

Optional header x-api-key raises your rate limit. Responses include RateLimit-* headers.

Live updates (SSE)

const es = new EventSource('/api/v1/matches/{matchId}/stream');
es.addEventListener('ball', (e) => console.log(JSON.parse(e.data)));
// events: toss, ball, innings_end, match_end   ·   all matches: /api/v1/stream

MCP server

Streamable HTTP endpoint: (stateless, JSON-RPC over POST).

Tools: list_matches, get_match, get_scorecard, get_commentary, get_squads, list_series, get_series, list_teams, get_team, find_players, get_player, get_rankings, list_news, search

Resources: cricket://matches/live, cricket://matches/{matchId} · Prompts: match_summary
